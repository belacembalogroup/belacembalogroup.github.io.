# Bela Cembalo Group

Sitio web de Bela Cembalo Group, publicado con GitHub Pages en https://belacembalogroup.com

- `atlantida/`: Casa Bela Cembalo - Atlántida (galería, datos de la casa, calendario y solicitud de reserva directa).
- `atlantida/calendario.js`: noches ocupadas, generado desde el iCal de Airbnb con `tools/actualizar_calendario.py`.
- `jaureguiberry/`: reservado para Bungalows Bela Cembalo - Jaureguiberry (temporada 2028).
